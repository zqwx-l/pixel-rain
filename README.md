## ✨ Features

- 🎌 **Japanese katakana** characters mixed with symbols and digits
- 🎨 **5 color themes** — Matrix Green, Cyberpunk, Blood Rain, Golden, Purple Haze
- ⚡ **Adjustable speed** — 9 levels from slow zen to blazing fast
- 📐 **Auto-resize** — adapts to terminal size changes
- ⏸️ **Pause/Resume** — freeze the rain mid-fall
- 🔀 **Dynamic density** — control how many drops fall
- 🚫 **Zero dependencies** — pure Python 3 standard library

## 🚀 Quick Start

### 🌐 Web Version (Mobile/Desktop)

**Play online:** [https://zqwx-l.github.io/pixel-rain](https://zqwx-l.github.io/pixel-rain)

Or run locally:
```bash
git clone https://github.com/zqwx-l/pixel-rain.git
cd pixel-rain
# Open index.html in your browser
```

### 💻 Terminal Version (CLI)

```bash
git clone https://github.com/zqwx-l/pixel-rain.git
cd pixel-rain
python3 pixel_rain.py
```

## 🎮 Controls

| Key | Action |
|-----|--------|
| `q` / `Ctrl+C` | Quit |
| `c` | Cycle color theme |
| `d` | Toggle density (40% / 70% / 100%) |
| `1` - `9` | Set speed (1=slow, 9=fast) |
| `Space` | Pause / Resume |

## 🎨 Themes

| Theme | Description |
|-------|-------------|
| Matrix Green | Classic green digital rain |
| Cyberpunk | Cyan + magenta neon |
| Blood Rain | Red cascade |
| Golden | Warm yellow/gold |
| Purple Haze | Magenta + blue |

## 📋 Requirements

- Python 3.6+
- Unix/Linux/macOS terminal (or WSL on Windows)
- Terminal with Unicode support (for katakana characters)

## 🖥️ Compatibility

Works on:
- ✅ Linux terminal
- ✅ macOS Terminal / iTerm2
- ✅ WSL (Windows Subsystem for Linux)
- ✅ SSH sessions
- ❌ Windows CMD/PowerShell (no termios support)
